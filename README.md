# Виртуальное министерство

Игра-симулятор на реальной политической истории Украины: **правительства 2005–2026** (от первого
кабинета Тимошенко до действующего кабинета Корецкого) прогнаны через тот же алгоритм, что и в
игре «Пульс сети» (сеть «Браво»):

1. **Компетентность** — у каждого политика четыре оценки 0–10 (управление, экономика,
   дипломатия, кризис-менеджмент); они сверяются с требованиями должности.
2. **Соционическая посадка** — тип политика (16 типов, библиотека `socionics-data.ts`)
   сверяется с предпочтениями должности: дихотомии + эталонные типы.
3. **Сплочённость** — полная таблица 14 интертипных отношений (`relations.ts`), от дуальности
   (+3) до конфликта (−2,5); штраф за смешение враждующих квадр.
4. **Контекст эпохи** — стабильность / реформы / кризис / война меняют вес должностей
   (в войне оборона ×1,6, МВД ×1,5, энергетика ×1,4; в кризис финансы ×1,5).

Итог кабинета: `45% компетентность + 25% соционика + 30% сплочённость` → рейтинг 0–100.

## Три вкладки

- **История кабинетов** — все 13 правительств с разбором по должностям, парам и квадрам,
  хроникой отставок и рейтингом.
- **Конструктор** — соберите свой кабинет из 100+ реальных политиков и посмотрите живую оценку.
- **Сравнение** — ваш кабинет встаёт в общий рейтинг с историческими правительствами.

## Данные и честность

- Составы кабинетов и хроника — **публичные факты** (Википедия: «Уряди України», kmu.gov.ua).
- Профессиональные компетенции и соционические типы — **экспертные игровые оценки**,
  а не научные данные: публичная соционика всегда спекулятивна.
- Ранние правительства 1991–2004 даны справочно, без разбора по членам.

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # прод-сборка
npx tsx scripts/test-ministry.ts   # проверка данных и движка
```

## Структура

```
src/lib/socionics-data.ts   # 16 типов, квадры, дихотомии (общая библиотека с «Браво»)
src/lib/relations.ts        # полная таблица интертипных отношений (общая библиотека)
src/lib/ministry-data.ts    # должности, политики, 13 кабинетов
src/lib/ministry-engine.ts  # движок оценки и рейтинга
src/app/page.tsx            # интерфейс (единственная страница)
scripts/test-ministry.ts    # тесты данных и движка
```
